# Scripts da revisão P1

- `revisar_p1_30_lotes_v1.py`: regras e patches da triagem inicial.
- `validar_p1_30_lotes_v1.py`: QA/regressão inicial.
- `gerar_qa_p1_v1.py`: planilha de revisão inicial.
- `validar_semantica_p1_v2.py`: validação das 1.093 pendências e regressão contextual.
- `criar_planilha_qa_p1_v2.py`: QA e planilha centralizada.
- Cópia dos três primeiros em `08-Entregas/P1-v1/scripts-revisao-p1-codigo-fonte.md`.

Os scripts foram importados das entregas da Biblioteca do ChatGPT, preservando seus textos. Pode ser necessário atualizar caminhos locais originalmente escritos para `/mnt/data`. A reexecução exige os CSVs de entrada, arquivados separadamente (ver manifesto). Não executá-los sem validar arquivos de entrada e saídas.
