# Scripts da revisão P2

- `revisar_p2_30_lotes_v1.py` e `p2_classificador_base.py`: regras da primeira passagem.
- `gerar_planilha_p2_v1.py`: resumo e amostra da P2 V1.
- `validar_pendencias_p2_v2.py`: segunda passagem de 8.813 pendências e testes de regressão.
- `gerar_qa_p2_v2.py`: planilha centralizada e amostragem P2.

Scripts originais arquivados em Git; podem conter caminhos da execução anterior em `/mnt/data`, que devem ser configurados para o Ubuntu. A pasta de origem CSV/ZIP é necessária para executar, e seus binários ainda não foram sincronizados com GitHub.
