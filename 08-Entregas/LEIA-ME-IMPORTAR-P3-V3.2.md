# Como importar P3 v3.2 no GitHub

1. Extraia o ZIP único em uma pasta temporária.
2. Leia `08-Entregas/P3-v3.2/RELATORIO-P3-V3.2.md` e `06-Decisoes/DEC-068 - Expansao seletiva P3 v3.2.md`.
3. Confira `SHA256SUMS-P3-V3.2.txt` com `sha256sum -c SHA256SUMS-P3-V3.2.txt` a partir da pasta extraída.
4. Copie os arquivos para o cofre/repositório GitHub preservando a estrutura de pastas; não sobrescreva versões anteriores ou históricos.
5. Revise o commit antes de enviar para o GitHub.
