# Portal de Calculadoras — Knowledge Vault

Vault de conhecimento para a classificação semântica das palavras-chave do portal de calculadoras.

Este repositório é aberto localmente no Obsidian e serve como memória global entre os lotes de classificação. A planilha continua sendo a base de dados; o vault registra a taxonomia, regras, ambiguidades, decisões, testes de regressão e o estado de cada lote.

## Base atual

Após a auditoria estrutural e a remoção dos dois metadados indevidos, a base de referência deve conter **294.905 palavras-chave únicas**.

A classificação semântica será feita em lotes, mas todas as decisões devem obedecer à mesma taxonomia global e às regras registradas neste vault.
